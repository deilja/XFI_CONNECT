# XFI CONNECT

Telegram-бот для автоматизации VPN-сервиса на базе 3X-UI/Xray.

## Возможности

- Управление несколькими 3X-UI/Xray серверами.
- VLESS, VMess, Trojan, Shadowsocks и другие конфигурации, поддерживаемые панелью.
- Создание, продление, отключение и удаление VPN-ключей.
- Статистика пользователей, ключей, серверов и трафика.
- Диагностика inbound, TLS и Reality.
- Тарифы, промокоды, баланс, оплаты и реферальная система.
- Автоматические уведомления и рассылки.
- Local AI Admin для диагностики и администрирования.
- Безопасное редактирование кода с проверками, снапшотами и rollback.

## Local AI Admin

Администратор может обращаться к встроенному AI-агенту обычным текстом.

Агент умеет:

- проверять состояние серверов и панелей;
- искать пользователей и ключи;
- продлевать и обслуживать ключи;
- анализировать логи;
- работать с балансом и оплатами;
- управлять страницами, кнопками, текстами и media;
- просматривать тарифы и промокоды;
- диагностировать inbound 3X-UI;
- анализировать и изменять код проекта;
- выполнять синтаксическую проверку и Ruff;
- создавать локальные точки восстановления перед изменением кода.

Изменения, влияющие на рабочую систему, проходят защитные проверки и не выполняются молча.

## Установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/deilja/XFI_CONNECT/main/install.sh)
```

После установки:

```bash
systemctl status xfi-connect
journalctl -u xfi-connect -f
```

## Ветки

- `main` — production-ветка XFI CONNECT.
- `feature/amnezia` — отдельная экспериментальная ветка интеграции Amnezia.

`main` не зависит от Amnezia.

## Обновления

Автоматическое получение и установка сторонних обновлений проекта отключены. Production-версия не обращается к стороннему upstream-репозиторию для проверки новых версий.

Изменения проекта выполняются только владельцем репозитория и устанавливаются контролируемым способом.

## Лицензия

XFI CONNECT — самостоятельный проект. Сторонние бренды, рекламные материалы и ссылки на исходный коммерческий проект в production-документации не используются.
