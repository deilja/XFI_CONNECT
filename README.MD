<h1 align="center">XFI CONNECT — Telegram VPN Bot</h1>

<p align="center">
  <b>Продажа, выдача и управление VPN-ключами через Telegram с поддержкой 3X-UI и Amnezia Admin API.</b>
</p>

---

## Возможности

### VPN и серверы

- 3X-UI как основной backend.
- Amnezia Admin API как дополнительный backend.
- Несколько VPN-серверов.
- Автоматическая проверка доступности панелей.
- Управление ключами, сроком действия и состоянием пользователей.
- Статистика пользователей, ключей и серверов.
- Работа с inbound 3X-UI и диагностика их параметров.
- Поддержка нескольких поколений API 3X-UI через профили совместимости.

### Amnezia

XFI CONNECT может использовать Amnezia Admin API без изменения существующей схемы серверов 3X-UI.

Для выбора Amnezia API используется явный префикс API-ключа:

```text
amnezia:YOUR_AMNEZIA_API_KEY
```

Поддерживаются операции:

- healthcheck `/healthz`;
- получение списка клиентов `/clients`;
- создание профиля;
- получение VPN-конфигурации;
- удаление профиля;
- включение/отключение профиля;
- получение статуса и статистики;
- получение информации о сервере;
- получение нагрузки CPU/RAM;
- продление срока действия профиля.

Существующий путь 3X-UI остаётся стандартным и не требует миграции базы данных.

### Платежи и бизнес

- Тарифы и сроки подписок.
- Промокоды и акции.
- Внутренний баланс.
- История и статистика оплат.
- Реферальная система.
- Рассылки и черновики маркетинговых сообщений.
- Управление пользователями и блокировками.

# Local YaAdmin / Yadreno Admin

В XFI CONNECT встроен локальный YaAdmin/DevAgent. Это не обычный чат: агент имеет набор инструментов для чтения проекта, диагностики, работы с базой данных, панелями и пользовательским интерфейсом.

Агент работает на сервере, где установлен XFI CONNECT, и может выполнять операции локально. Доступ разрешён только администраторам.

## Что умеет YaAdmin

### 1. Диагностика и серверы

- показать список VPN-серверов;
- показать активность серверов;
- проверить доступность панелей;
- показать версию панели;
- прочитать последние systemd-логи `xfi-connect`;
- проверить состояние inbound;
- показать список inbound;
- получить подробную информацию об inbound;
- проверить TLS/Reality/transport параметры inbound.

### 2. Пользователи

- найти пользователя по Telegram ID;
- найти пользователя по username;
- получить список ключей пользователя;
- получить информацию о конкретном ключе;
- показать баланс;
- показать статистику оплат;
- заблокировать/разблокировать пользователя;
- изменить баланс пользователя;
- установить индивидуальный реферальный коэффициент.

### 3. VPN-ключи

- статистика ключей;
- поиск ключа;
- продление ключа на указанное число дней;
- сброс уведомления о трафике;
- удаление ключа;
- поиск истекающих ключей;
- просмотр состояния ключей относительно панели.

Опасные операции не должны выполняться массово без явного запроса администратора.

### 4. Пользовательский интерфейс

YaAdmin может работать непосредственно с сохранёнными страницами бота:

- получить список страниц;
- посмотреть страницу;
- изменить текст страницы;
- установить/очистить media;
- изменить JSON кнопок;
- переименовать кнопку;
- скрыть или показать кнопку;
- изменить пользовательский интерфейс через свободный текст.

Поддерживается работа с основными пользовательскими экранами: главная, помощь, пробный период, оплата, тарифы, промокоды, ключи, продление, поддержка и дополнительные информационные страницы.

### 5. Рассылки

YaAdmin умеет работать с черновиком рассылки:

- посмотреть текущий черновик;
- подготовить текст;
- сохранить текст и фото в черновик;
- изменить содержимое до запуска.

**Автоматическая отправка массовой рассылки через Local YaAdmin намеренно не выполняется.** Финальный запуск должен подтверждаться отдельным действием администратора в админ-панели.

### 6. Тарифы и промо

- список тарифов;
- просмотр тарифа;
- изменение цены тарифа;
- список промокодов;
- просмотр состояния промокодов.

### 7. Синхронизация с панелями

YaAdmin умеет подготовить безопасное превью синхронизации ключей.

Автоматический destructive full-sync отключён: после просмотра превью администратор должен отдельно подтвердить применение через штатную админ-панель.

### 8. Работа с кодом

Local DevAgent дополнительно умеет:

- просматривать файлы проекта;
- искать код;
- анализировать Python-файлы;
- изменять файлы проекта;
- автоматически создавать снапшоты перед изменением;
- запускать Ruff;
- перезапускать `xfi-connect`;
- проверять состояние сервиса после перезапуска;
- выполнять rollback при неудачном изменении;
- показывать отчёт изменённых файлов;
- создавать отдельную сессию работы.

Защищённые области проекта (`.env`, база, `.git`, `venv`, `.snapshots`) исключены из обычного доступа агента.

## YaAdmin: интерфейс агента

В админ-панели доступны категории:

| Раздел | Возможности |
|---|---|
| 📊 Статистика | ключи, пользователи, истекающие ключи |
| 🖥 Серверы | состояние серверов и панелей |
| 🔑 Ключи | поиск, просмотр, продление, обслуживание |
| 👥 Пользователи | поиск, ключи, баланс, оплаты, бан |
| 📄 Страницы | просмотр и изменение UI |
| 💳 Тарифы | просмотр и изменение цен |
| 🎟 Промо | просмотр промокодов |
| 📡 Панель | healthcheck, inbound, синхронизация |
| 📢 Рассылка | работа с черновиком |
| 🛠 Код | чтение, изменение, проверка и rollback |
| 💬 Свободный чат | задачи обычным русским текстом |

Пример:

```text
Проверь все серверы и покажи, какой сейчас недоступен
```

или:

```text
Найди ключ 15 и продли его на 30 дней
```

или:

```text
Покажи inbound с Reality и проверь его состояние
```

# Безопасность YaAdmin

Архитектура агента разделяет операции чтения и изменения. Перед изменением кода создаётся снапшот. После изменения Python-кода выполняется синтаксическая проверка, а для операций с сервисом предусмотрен контроль результата и rollback.

Для критических операций используются дополнительные ограничения. В частности, Local YaAdmin не должен молча выполнять массовое удаление ключей или автоматический полный sync панели.

# Установка

Для установки используйте штатный установщик проекта:

```bash
bash <(curl -sL https://raw.githubusercontent.com/deilja/XFI_CONNECT/main/install.sh)
```

После установки бот запускается как systemd-сервис:

```bash
systemctl status xfi-connect
journalctl -u xfi-connect -f
```

# Настройка Amnezia

Amnezia Admin API должен быть доступен с сервера XFI CONNECT.

Пример параметров:

```text
Protocol: http/https
Host: адрес Amnezia API
Port: порт Admin API
API token: amnezia:YOUR_API_KEY
Protocol: amneziawg2
```

API-ключ передаётся в HTTP-заголовке `x-api-key`.

Рекомендуется размещать Admin API за HTTPS или ограничивать его доступ firewall/VPN-сетью.

## Статус интеграции Amnezia

Интеграция Amnezia Admin API добавлена в XFI CONNECT отдельным адаптером. Основной 3X-UI backend продолжает работать по существующей схеме.

Поддерживаемые операции Amnezia должны считаться подтверждёнными после проверки конкретной версии Admin API на целевом сервере.

Операции, которых нет в Amnezia API, не подменяются фиктивными 3X-UI вызовами.
