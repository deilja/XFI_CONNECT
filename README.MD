<h1 align="center">XFI CONNECT — Telegram VPN Bot</h1>

<p align="center"><b>Автоматизация VPN-сервиса на базе 3X-UI/Xray.</b></p>

## Возможности

### VPN и серверы

- 3X-UI/Xray как основной backend.
- Несколько VPN-серверов.
- VLESS (Reality, WS, gRPC), VMess, Trojan, Shadowsocks и другие конфигурации, поддерживаемые подключённой панелью.
- Автоматическая проверка доступности панелей.
- Управление VPN-ключами и сроком действия.
- Статистика пользователей, ключей и серверов.
- Диагностика inbound 3X-UI, включая TLS/Reality.

### Пользователи и бизнес

- Регистрация и управление пользователями.
- Тарифы и сроки подписок.
- Промокоды и акции.
- Внутренний баланс.
- История и статистика оплат.
- Реферальная система.
- Автоматические уведомления и рассылки.

## Local YaAdmin / DevAgent

В XFI CONNECT встроен локальный AI-агент для администрирования проекта. Администратор может обращаться к нему обычным русским текстом.

Агент умеет:

- проверять состояние VPN-серверов и панелей;
- читать systemd-логи `xfi-connect`;
- искать пользователей и ключи;
- продлевать и обслуживать ключи;
- работать с балансом, оплатами и банами;
- просматривать и изменять страницы и кнопки бота;
- управлять текстом и media интерфейса;
- просматривать тарифы и менять цены;
- работать с промокодами;
- готовить черновики рассылок;
- диагностировать inbound 3X-UI;
- просматривать, искать и изменять код проекта;
- выполнять синтаксическую проверку и Ruff;
- создавать снапшоты перед изменением кода;
- проверять результат перезапуска;
- выполнять rollback при неудачном изменении.

Опасные операции ограничены: массовые destructive-действия и полный sync панели не выполняются агентом молча.

## Установка

```bash
bash <(curl -sL https://raw.githubusercontent.com/deilja/XFI_CONNECT/main/install.sh)
```

После установки:

```bash
systemctl status xfi-connect
journalctl -u xfi-connect -f
```

## Архитектура

```text
Telegram
   │
   ▼
XFI CONNECT
   ├── Users / Keys / Payments / Tariffs
   ├── 3X-UI Adapter
   │     └── Xray
   └── Local YaAdmin / DevAgent
         ├── Database
         ├── Server health
         ├── Inbounds
         ├── UI pages
         ├── Tariffs / Promo
         ├── Logs
         └── Code + snapshots + rollback
```

## Ветки

- `main` — стабильная версия XFI CONNECT на базе 3X-UI/Xray.
- `feature/amnezia` — экспериментальная интеграция Amnezia Admin API. Она отделена от основной ветки и не входит в production `main`.

## Лицензия и исходный проект

XFI CONNECT развивается как отдельный проект на базе исходной идеи YadrenoVPN с собственной архитектурой и Local YaAdmin.
