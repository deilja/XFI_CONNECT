# AI Admin XFI CONNECT

Встроенный AI Admin предназначен для диагностики и администрирования самого XFI CONNECT.

## Возможности

AI Admin может:

- проверять состояние бота и VPN-серверов;
- анализировать systemd и application logs;
- искать пользователей, ключи, платежи и настройки;
- объяснять ошибки 3X-UI/Xray;
- диагностировать inbound, TLS и Reality;
- работать с тарифами, промокодами и UI;
- анализировать код проекта;
- предлагать и выполнять контролируемые изменения кода;
- запускать синтаксические проверки и Ruff;
- создавать локальные точки восстановления перед изменением файлов;
- проверять результат перезапуска.

## Безопасная модель

AI Admin не должен:

- получать секреты без необходимости;
- выполнять массовые destructive-операции без подтверждения;
- менять production-конфигурацию без проверки результата;
- синхронизировать проект с внешним upstream.

## Работа с интерфейсом

Команда `/yaa` может использоваться на поддерживаемой пользовательской странице для изменения текста, media, кнопок и других разрешённых элементов интерфейса.

Примеры:

```text
/yaa замени заголовок на «Добро пожаловать»
/yaa скрой кнопку Поддержка
/yaa добавь кнопку Новости со ссылкой https://example.com
```

Изменения интерфейса сначала должны проходить локальные проверки и сохраняться через предусмотренный механизм проекта.

## Работа с кодом

Для технической задачи формулируйте запрос конкретно:

```text
Проверь ошибку в обработке ключей, найди причину, внеси минимальное исправление и выполни синтаксическую проверку.
```

Для сложной задачи:

```text
Проведи аудит модуля серверов: найди ошибки, проблемы безопасности и race conditions. Исправляй только подтверждённые проблемы и после каждого изменения проверяй импорт.
```

## Диагностика сервера

Полезные команды:

```bash
systemctl status xfi-connect
journalctl -u xfi-connect -n 200 --no-pager
ss -lntup
```

## Внешние панели

AI Admin может анализировать результаты работы адаптера 3X-UI, но секреты панели не должны помещаться в промпты, README, логи или Git.

## Production-принцип

XFI CONNECT является самостоятельным проектом. Код production-ветки изменяется только контролируемыми изменениями в собственном репозитории.
