# Upstream YadrenoVPN — последние объявления

Источник: `plushkinv/YadrenoVPN`, ветка `main`.

## Версия 10.8 — 13.08.2026

- Добавлен способ оплаты **Crypto Pay через @CryptoBot**.
- Исправлены проблемы обновлений.
- Добавлено безопасное устойчивое обновление с возвратом к предыдущему состоянию при неудаче.
- Расширен кастомизатор: больше данных пользователя доступно для динамического формирования страниц.
- Для официальной 3X-UI 3.3.0+ усилена проверка подключения и сохранение подтверждённой версии панели.
- MTProto автоматически подключается к общей подписке начиная с 3X-UI 3.5.0.

## Версия 10.7 — 07.08.2026

- Последняя версия с поддержкой старых панелей 3X-UI ниже 3.3.0.
- Следующие версии требуют **официальную 3X-UI 3.3.0 или новее**.
- Обновление блокируется, если хотя бы у одной сохранённой панели версия ниже минимальной или версия не подтверждена.

## Версия 10.6 — 07.08.2026

- Последняя версия, поддерживающая выдачу отдельных VPN-ключей.
- Следующее направление — **только подписки**.
- Усилена безопасность автоматических обновлений: неуспешное обновление не устанавливается и не должно оставлять бота в нерабочем состоянии.
- Перед обновлением создаётся проверяемый снимок БД.
- Миграции проверяются до замены рабочей БД.
- При проблеме запуска предусмотрено автоматическое восстановление предыдущей версии.
- Добавлен автономный сценарий отката через `install.sh rollback`.

## Версия 10.5 — 05.08.2026

- Расширен кастомизатор.
- `0` в лимите трафика означает **безлимит**.
- `0` дней означает **без срока**.
- Автосброс трафика привязан к группе тарифов.
- Добавлена более гибкая настройка админского тарифа, включая количество устройств.
- Добавлена возможность заменить тариф пользователя из админки.
- Для тарифных групп можно создавать дополнительные пробные предложения через кастомизатор.
- Можно задавать режим пробников: один на пользователя или по одному на каждую тарифную группу.
- В карточке ключа отображаются тариф и количество устройств.
- Ключи пользователя по умолчанию отображаются как `Ключ №1`, `Ключ №2` и т. д.; формат названия можно кастомизировать.

## Что переносим в XFI_CONNECT

Функции выше считаются **upstream roadmap** для XFI_CONNECT. Они не должны переноситься слепым копированием файлов: XFI_CONNECT уже содержит собственные изменения и исправления, включая AI Agent, CI и работу с Ya.Seller.

При переносе сохраняем:

1. собственные изменения XFI_CONNECT;
2. существующую совместимость с текущей БД;
3. текущую архитектуру `vpn_api`/panel adapters;
4. исправления платежей;
5. CI и тестирование.

Приоритет переноса:

1. Crypto Pay;
2. безопасное обновление/rollback;
3. требования 3X-UI 3.3.0+;
4. тарифы `0 = безлимит/без срока` и автосброс по группам;
5. смена тарифа пользователем из админки;
6. дополнительные пробники по группам;
7. улучшения кастомизатора и user snapshot.
